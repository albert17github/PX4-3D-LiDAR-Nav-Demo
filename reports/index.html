One observable mainline

技术路线：连接成熟算法，不重写算法

每个框都是当前运行中的真实上游组件。项目代码只在组件边界做数据路由、目标接收、航点平滑、安全门和证据保存。

01 / PHYSICS

PX4 + Gazebo

SITL 飞控、动力学、IMU 与 3D LiDAR。

02 / ODOM

DLIO

激光惯性里程计输出 pose、velocity 与 yaw。

03 / FUSION

MAVROS + EKF2

PX4 融合外部位置、机体系速度与航向。

04 / MAP

OctoMap

将 pose + cloud 转为 0.4 m 三维占据地图。

05 / PLAN

MRS 3D A*

MinimalOctomapPlanner 生成完整绕障路径。

06 / GUARD

Safety gate

拒绝不完整路径、越界点和净距不足路径。

07 / EXECUTE

OFFBOARD

平滑航点、到达确认、AUTO.LAND。
